## Highlights

- Immersive interactive portfolio experience
- 3D visuals powered by React Three Fiber and Three.js
- Editable portfolio content, themes, fonts, and layout settings
- Persistent portfolio data and certificate media through Neon Postgres
- Responsive design for desktop and mobile screens

## Tech stack

Next.js · React · TypeScript · Three.js · React Three Fiber · GSAP · Neon Postgres

## Run locally

```bash
npm install
npm run dev
```

Create `.env.local` in the project root:

```env
DATABASE_URL=your_neon_pooled_connection_string
```

Then open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm run start
```
